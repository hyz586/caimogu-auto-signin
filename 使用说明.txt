【天下人苦采蘑菇久矣！！！】
采蘑菇论坛自动签到工具 - 源码版使用说明
==================================================

【重要提醒】
1. 请不要把自己的 auth_state.json 发给别人，它是你的登录状态文件。
2. 请不要把 replied_posts.json 发给别人，它是你的当天回复记录。
3. 本版本需要自行安装 Python 环境与 Playwright，适合开发者或想自行修改的用户。
   如果不想安装 Python，请使用免安装版（exe 版本）。

==================================================
【环境准备 - 首次使用必做】
==================================================

第 0 步：安装 Python 与依赖
  1. 安装 Python 3.8 以上版本（推荐 3.10），安装时勾选「Add Python to PATH」
  2. 在本文件夹打开命令行（在地址栏输入 cmd 回车），依次执行：
       pip install -r requirements.txt
       playwright install chromium
  3. 等待安装完成后，进入下面的快速开始

==================================================
【快速开始 - 只需 3 步】
==================================================

第 1 步：配置登录
  双击「启动签到.bat」，输入 2
  浏览器会打开采蘑菇登录页
  在浏览器中手动登录成功后，回到命令行窗口按回车保存登录状态

第 2 步：测试运行
  双击「启动签到.bat」，输入 3
  这一步只预览评论，不会真的发帖
  确认评论生成正常后再进行下一步

第 3 步：手动运行一次
  双击「启动签到.bat」，输入 1
  脚本会在多人运动圈自动回复当天剩余数量的帖子

确认手动运行没问题后，可以设置开机自启动，以后就不用管了！

==================================================
【设置开机自启动】
==================================================

双击「设置开机自启.bat」
以后每次开机登录 Windows 后，脚本会自动后台运行签到。

如需取消，双击「取消开机自启.bat」即可。

==================================================
【防重复机制】
==================================================

脚本会把当天已成功回复的数量记录到 replied_posts.json。
- 同一天多次开机不会无限重复发帖
- 如果今天已经完成 3 条，后续运行会自动跳过
- 如果中途只完成 1 或 2 条，下次运行只会补剩余数量

==================================================
【评论生成说明】
==================================================

新版会先判断帖子是否适合普通用户自然回复：
- REPLY：有明确可回应点，才生成 15～35 个汉字的短回复
- SKIP：信息太少、重复、无关或硬回复会像水贴时，直接跳过该帖子

回复会尽量抓住标题或正文中真实出现的具体细节，不补造事实，不假装亲身经历。
已禁止"感谢分享""支持一下""学到了""坐等后续""确实如此""期待更新""前排围观""有道理""这波可以"等空泛套话。

【AI 模式，可选】
如果想让评论更像真人，可以申请 DeepSeek API Key。
用记事本打开 config.json，把 deepseek_api_key 后面的空字符串改成你的 Key。
保存后脚本会自动使用 AI 根据标题和正文先判断 REPLY/SKIP，仅在 REPLY 时生成评论。

默认使用 DeepSeek 官方接口（deepseek-chat 模型）。
如果想用商汤日日新的免费额度，把以下三项都改掉：
  deepseek_api_key    填商汤的 API Key
  deepseek_base_url   改成 https://token.sensenova.cn/v1
  deepseek_model      改成 deepseek-v4-flash
这样每 5 小时有 1500 次免费调用，签到完全够用。
运行后可在 signin_log.txt 里看到实际请求和返回的模型名。

【常见问题】
==================================================

Q：登录状态失效怎么办？
A：重新运行「启动签到.bat」，输入 2，再登录一次。

Q：如何取消开机自启动？
A：双击「取消开机自启.bat」即可。

Q：想改每天回复数量怎么办？
A：用记事本打开 config.json，修改 reply_count 的数值。

Q：想改板块怎么办？
A：用记事本打开 config.json，修改 circle_url 为目标板块网址。

Q：想显示浏览器窗口（看运行过程）怎么办？
A：用记事本打开 config.json，把 headless 改成 false。

Q：提示「未安装 Playwright」怎么办？
A：在命令行执行 pip install -r requirements.txt 和 playwright install chromium。

Q：出问题时发哪些文件给排查？
A：优先发送 run_log.txt、last_command_output.txt、signin_log.txt。

Q：第一次运行很慢？
A：第一次运行需要初始化浏览器内核，会慢一些，之后就快了。

==================================================
【命令行直接运行】
==================================================

如果不通过 bat 菜单，也可以直接用命令行：

  python caimogu_signin.py            执行自动签到
  python caimogu_signin.py --login    配置登录（首次使用）
  python caimogu_signin.py --test     测试评论生成效果
  python caimogu_signin.py --help     显示帮助

【config.json 配置项说明】
==================================================

{
  "circle_url": "https://www.caimogu.cc/circle/308.html",  // 签到板块网址
  "reply_count": 3,       // 每天回复数量
  "min_delay": 8,         // 每条回复最小间隔（秒）
  "max_delay": 20,        // 每条回复最大间隔（秒）
  "headless": true,       // 是否无头模式（true=不显示浏览器窗口）
  "page_timeout_ms": 90000,  // 页面超时时间（毫秒）
  "deepseek_api_key": "",    // API Key（可选，AI评论用）
  "deepseek_base_url": "https://api.deepseek.com/v1",   // API 地址（官方默认）
  "deepseek_model": "deepseek-chat"   // 模型名（官方默认）
}

// 商汤日日新用户改成：
//   deepseek_base_url: "https://token.sensenova.cn/v1"
//   deepseek_model:    "deepseek-v4-flash"
